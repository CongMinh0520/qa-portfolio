# QA Portfolio — JAMstack

Static-first portfolio built with React, Vite and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The deployable static output is generated in `dist/`. Deploy it to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any static host. There is no server runtime or database required.
